# משימות שלי — גרסת דפדפן

הגרסה הוובית של אפליקציית ניהול המשימות **משימות שלי** (האפליקציה המקורית היא אפליקציית Windows ב-Electron).

הדגמה חיה: **https://adesbusy.github.io/mytasks-web/**

## מה זה

- **קבוצות** — יצירה, שינוי שם, צבע, מחיקה.
- **משימות** — כותרת, הערות, עדיפות, תאריך יעד.
- **תתי־משימות** — סימון בוצע, עריכה, מחיקה.
- **תצוגות חכמות** — הכל / היום / שבוע קרוב / הושלמו.
- **חיפוש, סידור, גרירה ושחרור**, ערכת נושא כהה/בהירה (RTL).

## איפה הנתונים נשמרים

הנתונים נשמרים **ב-localStorage של הדפדפן** (לא בשרת). כלומר:

- אין רישום ואין סנכרון — הכול מקומי לדפדפן ולמכשיר.
- לגיבוי/העברה, השתמשו ב״**ייצוא**״ (מוריד קובץ JSON) ו״**ייבוא**״.

פורמט הנתונים זהה לזה של אפליקציית ה-Windows — קובץ שיוצא מכאן נכנס ישירות
לאפליקציית שולחן העבודה, ולהיפך.

## מבנה

```
index.html     הממשק (עברית, RTL)
styles.css     עיצוב
renderer.js    לוגיקת הממשק (זהה לאפליקציית Windows)
bridge.js      מתאם אחסון דפדפן (מחליף את הגשר של Electron)
```
